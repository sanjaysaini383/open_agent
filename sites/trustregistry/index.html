File a report

The subject does not have to be registered. Partner sites file the same report through a TrustRegistry window that a person here confirms.

Suspend, revoke or reinstate

Sets the registry's live status. It cannot be better than the signed attestation says: that needs a newly signed attestation, issued offline.

Register a subject

Recorded as pending: it has no signed attestation, so callers treat it as unverified until the registry signs one.

Demo data
