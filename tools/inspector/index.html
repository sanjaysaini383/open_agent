Agent Interoperability Inspector Can another site's browser load and run this agent network?
Documentation

Enter a site's address, the folder that holds its agent-manifest.json, or a network URL (that folder, then the network name). The checks run in this browser, from , so CORS is enforced for real. Only the site's public files are read; nothing is sent to it but the requests themselves.

Checks follow the Worldwide Agentic Web MVP specification. Parsing and validation are done by the official agentic-web browser runtime, unchanged. A reusable, dependency-free tool from the ReliefMesh project; Apache-2.0.
